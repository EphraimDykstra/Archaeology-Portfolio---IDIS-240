# IDIS 240 — Introduction to Archaeology
## Course Portfolio | Ephraim Dykstra | Calvin University | Spring 2026

**Live site:** https://ephraimdykstra.github.io/Archaeology-Portfolio---IDIS-240/

---

An interactive course portfolio for IDIS 240 (Introduction to Archaeology) with Prof. Darrell Rohl at Calvin University.

### What's inside

- History of the discipline — from Nabonidus to LiDAR
- The archaeological record — artifacts, ecofacts, features, context
- Fieldwork methods — survey, excavation, remote sensing
- Dating methods — dendrochronology, radiocarbon, stratigraphy
- **Who's Dead?** — an interactive archaeological identification game with 5 real cases
- Post-midterm topics — environmental archaeology, bioarchaeology, trade, ethics, heritage
- Archaeology & Christian faith — a Calvin University perspective
